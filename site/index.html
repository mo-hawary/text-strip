Scrolling announcement bar

text-strip

Drop-in scrolling announcement bar. LTR and RTL, Arabic-first, Shadow DOM isolated, under 4 KB, zero dependencies.

Try the playground View on GitHub View on npm

Why text-strip

One config object, no framework, and nothing leaks in or out of the page.

  • LTR and RTL

    Scroll direction follows the text. Arabic reads naturally as it enters the screen.

  • Arabic-first

    Mixed Arabic and English items keep the word order of each item intact.

  • Shadow DOM isolated

    Its styles cannot leak out, and your page CSS cannot reach in.

  • Under 4 KB

    A small bundle that is fast to load, even from a CDN.

  • Zero dependencies

    Nothing else to install, audit or update. Works with plain HTML.

  • Accessible

    Pauses on hover and focus, respects reduced motion, and labels its close button.

Install

Use npm for a bundler project, or a script tag for a plain page.

npm

npm install text-strip

Script tag

<script src="https://cdn.jsdelivr.net/npm/text-strip@0.1/dist/index.global.js"></script>
