Drop-in announcement strip

A scrolling strip fixed to the top or bottom of the page. It loops forever, works left to right or right to left, and renders in its own shadow root so the host site's CSS cannot break it.

The header above is sticky and offsets itself with top: var(--text-strip-height), so it stays below the top strip.
